# Impeccable Design Context

## Design Context

### Users
Criadores — pessoas que trabalham com conteúdo, design, código e fluxos criativos. Usam o tropicOS como hub central para seus skills de IA, ativando-os em conversas para amplificar seu processo criativo. O contexto de uso é focado, iterativo e frequente.

### Brand Personality
Moderno, fluido, expressivo. A marca deve sentir como uma ferramenta feita por criadores para criadores — não corporativa, não genérica, não mais um SaaS cinza. Deve ter personalidade própria e uma energia criativa latente.

### Aesthetic Direction
- **Tom visual**: Editorial criativo — limpo mas com caráter. Não minimalismo morto, mas precisão com alma.
- **Anti-referências**: Generic SaaS (Notion, Linear clones), dashboards corporativos, interfaces cinza sem opinião.
- **Modo**: Light mode (fundo branco/off-white, acento verde `#32EE66`)
- **Energia**: Rápido, fluido, confiante. Cada interação deve parecer intencional.

### Design Principles
1. **Criadores primeiro** — cada decisão de design deve reduzir fricção para o fluxo criativo, não adicionar overhead cognitivo.
2. **Personalidade sem ruído** — ter um ponto de vista estético claro sem sobrecarregar a interface com elementos desnecessários.
3. **Tipografia como voz** — o tipo carrega a personalidade da marca; fontes genéricas (system-ui, Inter, Roboto) são proibidas.
4. **Fluido e responsivo** — transições e espaçamentos devem sentir naturais, não mecânicos.
5. **Verde como acento vivo** — `#32EE66` é a cor de vida da interface; usá-la com intenção, não decorativamente.
